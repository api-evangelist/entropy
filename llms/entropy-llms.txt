# Entropy

> Entropy is a threshold-signature network for trustless, programmable key management and distributed key generation (DKG) — "the Autonomous Agent Network." Users and agents generate cryptographic signatures without any single party ever holding the private key, gated by on-chain WASM "programs" that define exactly when a signature may be produced. Built as a Substrate-based blockchain with Threshold Signature Scheme (TSS) servers running in Trusted Execution Environments (TEEs). Backed by a16z.
